Hill Cipher

Encrypt pairs of letters with a matrix.

Principle

Each letter becomes a number (A=0 … Z=25). Letters are encrypted two by two (x, y) with a 2×2 key matrix, modulo 26:

1st letter = (a·x + b·y) mod 26
2nd letter = (c·x + d·y) mod 26

Decryption uses the inverse matrix: it exists only if the determinant (a·d − b·c) is coprime with 26.

Uppercase and lowercase are accepted; the result is written in uppercase, without spaces.

Padding: if the number of letters is odd, an X is added at the end before encryption. When decrypting, the final X is removed: the original message is recovered.

"HELLO" (5 letters) → HELLOX → encrypted (6 letters)
decrypted: HELLOX → HELLO (the X is removed)

Flaws and solutions

FlawSolution
Negative determinant (e.g. a·d − b·c = −5): if the negative value is kept, the inverse is "not found" and a valid key is wrongly refused. Applied The determinant is brought back to 0…25: det mod 26 (adding 26 while it is negative). Then we check that gcd(det, 26) = 1.
Example: K = [1 2 ; 3 1] → det = 1×1 − 2×3 = −5 → −5 + 26 = 21; gcd(21, 26) = 1 → valid key; inverse of 21 = 5 (21×5 = 105 = 4×26 + 1).
Counter-example: [1 3 ; 4 2] → det = −10 → 16; gcd(16, 26) = 2 → refused (use the "Random valid key" button to get a good one).
Ambiguous padding X: if the original message has an even number of letters and already ends with X (e.g. "AX"), that X is wrongly removed when decrypting. Applied A warning is shown at encryption in this case. To avoid it: add one more letter at the end of the message, or rephrase.
Linear algorithm: with a known plaintext (2 blocks) and its ciphertext, the key is found by a simple computation (see the attacker below). Use a bigger matrix (3×3 or more) and add a non-linear part (for example a shift vector added after the multiplication: "affine" Hill).
Same blocks → same results: repetitions in the message stay visible. Chain the blocks (CBC mode): each block is mixed with the previous encrypted block before being encrypted.
Few keys: only 157,248 valid 2×2 matrices: a computer tests them all. Bigger matrices (3×3 → about 1.6×10¹² valid keys) or a modern cipher (AES).
Attacker: known plaintext

The attacker knows a plain message and its encrypted version. Since Hill is linear, he solves K · P = C (P = plain blocks, C = cipher blocks) and finds the key without guessing.
