Caesar Cipher

Each letter is shifted by k places in the alphabet.

Encrypt / Decrypt

Uppercase and lowercase are kept as typed (Hello → Khoor). Spaces are removed. Key: 1 to 25.

History

Every operation is saved (it stays after reloading the page).

Flaws and solutions
FlawSolution
Key 26 (or 0): the message does not change.
Shifting by 26 = one full turn of the alphabet.		 Applied The key is reduced to 0–25 (modulo 26) and 0 is refused.
Example: key 26 → refused (ABC → ABC). Key 29 → accepted as key 3 (29 − 26).
Visible spaces and punctuation: word lengths help to guess the text. Applied Spaces are removed before encryption.
Example: "Bonjour le monde" → "Bonjourlemonde" → "Erqmrxuohprqgh" (key 3).
Only 25 keys: an attacker simply tries them all (brute force). Use a longer key: a word that gives a different shift for each letter (Vigenère), or a modern cipher (AES).
Frequency analysis: the same letter always gives the same cipher letter; E stays the most frequent letter. Change the shift from one letter to the next (Vigenère) to break the frequencies.
Known plaintext: a single pair (plain letter, cipher letter) reveals the key. Never reuse the same key for several sensitive messages; change the key often.

The attacker does not know the key: he tries the shifts 1 to 25 (26 is useless: it gives the same text back). The text closest to French is marked ★.
