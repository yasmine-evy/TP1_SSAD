Password System

Create and validate three password types, explore dictionary and brute-force attacks, and test password protections.

Password Generator & Validation

Passwords are generated with the browser's secure random generator. You can also type your own password, then click Check: the page tells you if it respects the rule of the type, and what to change if it does not.

Type 1 — 3 characters: each 0 or 1

2³ = 8 possible combinations.

Type 2 — 4 characters: each 1, 2, 3 or 4

4⁴ = 256 possible combinations.

Type 3 — Set of characters: a-z, A-Z, 0-9, +, *

Cipher settings for attacks

Choose the cipher and key used to encrypt the target password and each attack candidate before comparison.

Dictionary attack

A dictionary attack tries likely passwords from a word list, starting with the most common ones. Add your own words to see how a larger, more realistic list changes the attack.

Protection Dictionary Attack

1. Block common passwords

Check passwords against a small list of common choices, such as 123456 or password123. If one matches, choose a stronger password.
