How each algorithm works

Caesar: the alphabet has 52 symbols, a–z then A–Z. Each letter is shifted by k places (key 1 to 51, left or right) and wraps around (z → A, Z → a). Spaces disappear from the encrypted text and come back at decryption. A key like 55 is reduced modulo 52 (→ 3); 0 and 52 are refused (the text would not change).

Hill (2×2): letters are encrypted two by two with a matrix, modulo 26. Uppercase/lowercase follow the position of each letter (Hello → Hiozhn); the decrypted message is exactly the one sent. The determinant is brought back to 0…25 (negative values handled) and must be coprime with 26. If the number of letters is odd an X is added; the final X is removed when decrypting.

Playfair: a 5×5 table is built from a secret key (I and J share a cell). The text is cut into pairs (the padding letter is inserted between two equal letters and at the end if the length is odd), then each pair is encrypted with the row / column / rectangle rule. The case of each letter is kept by position.

Spaces (all algorithms): before encryption each space is replaced by the two letters Qs (and a real q / Q is written Qq / QQ), so the encrypted text contains no spaces. At decryption Qs becomes a space again: Hello World is recovered exactly.

Both sides must use the same algorithm and the same key, otherwise the message is not recovered.
